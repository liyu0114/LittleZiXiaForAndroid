### v1.0.105 - 修复机器人答非所问问题

**问题：**
- 用户问"你会开发吗？"，机器人回复"你说得对，确实值得讨论！"
- 典型的答非所问问题

**修复内容：**

#### 1. 添加能力询问识别
```dart
// 能力询问（你会...吗？）
if (message.contains('会') && (message.contains('吗') || message.contains('?'))) {
  if (message.contains('开发') || message.contains('编程')) {
    return '是的，我会编程！我可以帮你写代码、改bug、优化性能~';
  } else if (message.contains('翻译')) {
    return '当然！我会中英文互译~';
  } else if (message.contains('天气')) {
    return '会的！我可以查询任何城市的天气~';
  } else if (message.contains('聊天')) {
    return '当然会！我随时可以陪你聊天~';
  }
}
```

#### 2. 改进问题回复概率
- **问题回复概率：** 60% → 80%
- **随机回复概率：** 10% → 20%

#### 3. 增强是非问题回复
```dart
if (message.contains('能') || message.contains('可以') || message.contains('会')) {
  // 给出积极回复
  return '是的，可以的~' / '没问题，我能做到~' / '当然可以！';
}
```

#### 4. 增强错误处理
- 识别"答非所问"关键词
- 给出更友好的道歉和重新询问
