# 任务分解测试用例

## 用户请求
"我所在的地方这5天的天气如何"

## 期望分解结果

### 子任务 1：获取当前位置
- **技能：** location
- **描述：** 获取当前位置
- **参数：** 无
- **返回：** 经纬度 + 地点名称（例如：北京市）

### 子任务 2-6：查询天气
- **技能：** weather
- **描述：** 查询 X 天的天气
- **参数：** 
  - location: 北京市
  - date: 今天/明天/后天/大后天/第5天
- **返回：** 天气信息

### 最终结果
汇总所有天气信息，生成5天天气预报

## 实现思路

1. **任务分解器**检测到：
   - "我所在的地方" → 需要 location skill
   - "5天的天气" → 需要 weather skill，调用 5 次

2. **执行顺序**：
   - 先执行 location 获取地点
   - 然后循环 5 次 weather 查询天气
   - 最后汇总结果

3. **LLM Prompt 优化**：
```
你是一个任务分解专家。请将用户请求分解为子任务。

用户请求：我所在的地方这5天的天气如何

请按以下格式输出：
1. [location] 获取当前位置
2. [weather] 查询今天的天气
3. [weather] 查询明天的天气
4. [weather] 查询后天的天气
5. [weather] 查询大后天的天气
6. [weather] 查询第5天的天气
```
