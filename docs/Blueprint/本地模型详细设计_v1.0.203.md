## 三、技术实现细节

### 3.1 llama.cpp Android移植

| 步骤 | 内容 | 文件 |
|------|------|------|
| 1 | NDK环境配置 | `local.properties` |
| 2 | CMakeLists.txt编写 | `android/app/src/main/jni/CMakeLists.txt` |
| 3 | JNI接口定义 | `LocalModelPlugin.java` |
| 4 | llama.cpp C API封装 | `llama-android.cpp` |

**JNI接口设计：**
```java
// Java/Kotlin侧
public class LocalModelPlugin {
    public CompletableFuture<List<Map>> getModels();      // 获取可用模型
    public CompletableFuture<Boolean> loadModel(String modelId);  // 加载模型
    public CompletableFuture<String> generate(String prompt);     // 生成文本
    public CompletableFuture<Void> unload();            // 卸载模型
    public CompletableFuture<Boolean> isLoaded();       // 检查是否加载
}
```

### 3.2 模型管理

| 功能 | 说明 |
|------|------|
| 模型存储 | `app_data/models/` 目录 |
| 模型格式 | GGUF (Q4_0, Q5_1量化) |
| 模型下载 | 从网络/HTTP获取 |
| 模型切换 | 支持多模型切换 |

### 3.3 内存管理

| 场景 | 策略 |
|------|------|
| 模型加载 | mmap映射，按需加载 |
| 推理 | 流式输出，减少峰值内存 |
| 卸载 | 显式卸载，释放内存 |

### 3.4 华为NPU适配（Phase 2）

**达芬奇NPU架构：**
- 支持INT8/FP16推理
- 支持自定义算子
- 需要编写昇腾适配层

**llama.cpp后端：**
- 已有CUDA/Metal后端
- 需新增Huawei NPU后端（类比）

## 五、接口设计

### 5.1 Flutter接口

```dart
class LocalModel {
  final String id;
  final String name;
  final int sizeMB;
  final int contextLength;
  final bool isLoaded;
}

class LocalModelManager extends ChangeNotifier {
  List<LocalModel> get models;
  LocalModel? get currentModel;
  bool get isLoading;
  bool get isInitialized;

  Future<void> initialize();
  Future<bool> loadModel(String modelId);
  Future<String> generate(String prompt, {
    int maxTokens = 256,
    double temperature = 0.7,
  });
  Future<void> unloadModel();
  Future<bool> isModelLoaded();
}
```

### 5.2 状态机

```
[Uninitialized]
       ↓ initialize()
[Initialized] ← → [Loading]
       ↑              ↓
    unload()    [Ready]
       ↑              ↓
    unload()    [Generating]
```
