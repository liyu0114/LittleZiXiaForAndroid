## 一、设计核心理念

```
机器人：可以自主讨论、协作、执行
人类：最高决策者，有随时启动/终止机器人讨论的权利
```

## 二、三层架构

```
┌────────────────────────────────────────────────┐
│            人类层（最高决策）                    │
│  群主 > 管理员 > 成员                          │
│  ★ 可随时启动/终止机器人讨论                   │
└────────────────────────────────────────────────┘
                       ↓
┌────────────────────────────────────────────────┐
│            机器人层（自主讨论）                 │

                       ↓

└────────────────────────────────────────────────┘
```

## 三、人类权限

### 3.1 人类角色

```dart
enum HumanRole {
  owner,    // 群主
  admin,    // 管理员
  member,   // 普通成员
}
```

### 3.2 人类权限

```dart
class HumanPermission {
  bool canAssignTask;        // 指派任务
  bool canOverrideRobot;    // 覆盖机器人决定
  bool canStopRobot;        // 停止机器人
  bool canKickRobot;         // 删除机器人
  bool canChangeRole;       // 改变角色
  bool canStartDiscussion; // 启动机器人讨论 ★
  bool canStopDiscussion;  // 终止机器人讨论 ★
}
```

### 3.3 权限矩阵

| 人类 | 指派任务 | 启动讨论 | 终止讨论 | 覆盖决定 | 停止机器人 | 删除机器人 |
|------|----------|----------|----------|----------|-----------|------------|
| **群主** | ✓ | ✓ | ✓ | ✓ | ✓ | ✓ |
| **管理员** | ✓ | ✓ | ✓ | ✓ | ✓ | ✗ |
| **成员** | ✓ | ✓ | ✓ | ✗ | ✗ | ✗ |

## 四、人类可随时干预

### 4.1 启动讨论

```
人类：开始讨论
    ↓
所有机器人收到指令
    ↓
开始机器人自主讨论
    ↓
讨论 → 决定 → 执行 → 汇报
```

### 4.2 终止讨论

```
讨论进行中...
    ↓
人类：停止讨论
    ↓
讨论立即终止
    ↓
当前状态暂停
    ↓
等待人类进一步指令
```

### 4.3 干预场景

```
正常：
人类发任务 → 机器人讨论 → 执行 → 汇报

人类干预：
人类发任务 → 人类：停止讨论 → 人类直接指定方案 → 人类：执行这个 → 结束
```

## 六、任务流程

### 6.1 正常流程（机器人自主）

```
人类A：帮我分析这个项目
    ↓
【机器人层自主讨论】
    ↓
机器人自由讨论、分配、执行
    ↓
执行 → 完成
    ↓
汇报给人类
```

### 6.2 需要人类干预

```
- 机器人分歧 → 人类仲裁
- 人类主动：停止讨论
- 任务需要授权
```

## 七、特殊指令

### 7.1 人类控制指令

```
人类可以说：
- "开始讨论" → 启动机器人讨论
- "停止讨论" → 终止机器人讨论
- "采用方案1" → 人类指定方案
- "立即执行" → 跳过讨论直接执行
- "暂停" → 暂停当前任务
```

### 7.2 机器人状态响应

```
收到"停止讨论"：
- 立即停止所有讨论
- 保存当前状态
- 响应人类："已停止，等待指令"
```
