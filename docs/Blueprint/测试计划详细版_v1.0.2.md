## 八、测试命令

### 自动测试

```bash
# 运行单个服务测试
flutter test test/task_decomposer_test.dart

# 运行所有测试
flutter test

# 运行指定目录
flutter test test/
```

### 真机测试

```bash
# 查看设备
adb devices

# 安装
flutter install

# 查看日志
adb logcat -s Flutter:V
```
