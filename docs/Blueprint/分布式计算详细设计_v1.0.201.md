## 一、两个层次区分

### 层次1：分布式计算（类Hadoop）

- **粒度**: 子任务（业务级别）
- **单位**: "查天气"这样的完整任务
- **架构**: 主从模式（Master分配）
- **目标**: 把大任务拆成独立子任务并行执行

### 层次2：贡献算力（类CUDA）

- **粒度**: 计算单元（底层）
- **单位**: "算矩阵乘法"这样的计算
- **架构**: 对等模式（各设备贡献）
- **目标**: 底层计算并行

**注意**: 两个层次需要不同的架构支撑！

## 二、层次1：分布式计算架构（类Hadoop）

### 2.1 系统架构

```
┌─────────────────────────────────────────┐
│           Master（任务分解器）            │
│  1. 接收用户任务                         │
│  2. 判断是否需要多设备                  │
│  3. 拆分成子任务                         │
│  4. 分配给从设备                        │
│  5. 汇总结果                            │
└─────────────────────────────────────────┘
              ↓         ↓         ↓
         设备A      设备B      设备C
        子任务1   子任务2   子任务3
              ↓         ↓         ↓
              └────────┴────────┘
                    ↓
               汇总结果
```

### 2.2 任务流程

| 步骤 | 操作 | 说明 |
|------|------|------|
| 1 | 接收任务 | "分析北京、上海、深圳天气" |
| 2 | 任务分解 | ["查北京","查上海","查深圳"] |
| 3 | 设备选择 | 根据算力分发给设备 |
| 4 | 分发执行 | 发送子任务到各设备 |
| 5 | 等待完成 | 等待各设备返回 |
| 6 | 结果汇总 | 合并返回给用户 |

### 2.3 任务格式

```dart
// 主任务
class DistributedTask {
  String taskId;
  String originalInput;
  List<SubTask> subTasks;
  TaskStatus status;
  DateTime createdAt;
}

// 子任务
class SubTask {
  String subTaskId;
  String input;
  String assignedDeviceId;
  TaskStatus status;
  String? result;
  DateTime? startedAt;
  DateTime? completedAt;
}

// 设备能力
class DeviceCapability {
  String deviceId;
  DeviceType type; // Android/Windows/MAC
  int cpuCores;
  int memoryGB;
  bool hasLocalModel;
  String? modelName;
  int score; // 算力评分
}
```

### 2.4 任务分发算法

```dart
enum SelectStrategy {
  // 轮询 - 轮流使用
  roundRobin,
  
  // 算力优先 - 用最强的
  capabilityFirst,
  
  // 就近 - 用同一个WiFi最近的
  nearest,
  
  // 负载均衡 - 用最闲的
  loadBalance
}
```

### 2.5 设备选择（推荐算力优先）

```dart
class DeviceSelector {
  // 算力优先选择
  Device selectByCapability(List<Device> devices) {
    // 按算力评分排序
    devices.sort((a, b) => b.score.compareTo(a.score));
    // 返回最强的
    return devices.first;
  }
}
```

## 五、执行流程

### 完整流程

```
1. 用户发起任务
   ↓
2. Master判断是否需要多设备
   ├─ 是 → 进入分布式流程
   └─ 否 → 本地执行
   ↓
3. Master任务分解
   输入："分析北京、上海、深圳天气"
   分解：["查北京","查上海","查深圳"]
   ↓
4. 设备选择（算力优先）
   ┌─────────┐
   │ 设备A   │ score=100（最强）
   │ 设备B   │ score=80
   │ 设备C   │ score=60
   └─────────┘
   ↓
5. 分发子任务
   设备A←子任务1
   设备B←子任务2
   设备C←子任务3
   ↓
6. 并行执行
   ↓
7. 结果回收
   ↓
8. 汇总返回
```

## 六、错误处理

| 情况 | 处理 |
|------|------|
| 设备离线 | 重试其他设备 |
| 执行超时 | 杀死任务，返回超时错误 |
| 部分失败 | 返回成功的结果+失败标记 |
| 全部失败 | 返回失败，提示原因 |
