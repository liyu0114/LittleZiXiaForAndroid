## 一、目标

当没有现成Skill可用时，自动创建新Skill（可能包括软件/脚本）

---

## 二、产物类型

技能自造可以生成多种类型：

| 类型 | 说明 | 扩展名 | 示例 |
|------|------|--------|------|
| **Skill** | 技能代码 | .dart | skill_weather.dart |
| **Script** | 脚本文件 | .sh/.py/.js | install.sh |
| **Config** | 配置文件 | .yaml/.json | config.yaml |
| **App** | Flutter应用 | .dart | calculator.dart |
| **Tool** | 命令行工具 | .sh | mytool.sh |

## 三、完整流程

```
用户需求
    ↓
┌─────────────────────────────────────────┐
│         产物类型判断（LLM）              │
│  需要什么类型的产物？                    │
└─────────────────────────────────────────┘
    ↓
┌─────────────────────────────────────────┐
│  产物生成                               │
│  ════════════════════                   │
│  • Skill → 生成Skill代码                │
│  • Script → 生成脚本文件                 │
│  • Config → 生成配置文件                  │
│  • App → 生成Flutter代码                 │
│  • Tool → 生成命令行工具                 │
└─────────────────────────────────────────┘
    ↓
┌─────────────────────────────────────────┐
│  写入文件系统                            │
│  ════════════════════                   │
│  • 写入对应目录                          │
│  • 设置可执行权限                        │
└─────────────────────────────────────────┘
    ↓

└─────────────────────────────────────────┘
    ↓

```

## 四、每种产物的详细设计

### 4.1 生成Skill（现有流程）

```dart
class SkillGenerator {
  Future<Skill> generateSkill(String need) async {
    String code = await llmGenerate(SkillPrompt);
    await writeFile('skills/skill_xxx.dart', code);
    Skill skill = parseSkill(code);
    await skillManager.register(skill);
    return skill;
  }
}
```

### 4.2 生成Script

```dart
class ScriptGenerator {
  Future<String> generateScript(String need) async {
    String script = await llmGenerate(ScriptPrompt);
    
    // 判断类型
    String ext = need.contains('shell') ? '.sh' 
               : need.contains('python') ? '.py' 
               : '.js';
    
    String fileName = 'script_$need$ext';
    await writeFile('scripts/$fileName', script);
    
    // 设置执行权限
    await Process.run('chmod', ['+x', fileName]);
    
    return fileName;
  }
}
```

### 4.3 生成Config

```dart
class ConfigGenerator {
  Future<String> generateConfig(String need) async {
    String config = await llmGenerate(ConfigPrompt);
    
    String fileName = 'config_$need.yaml';
    await writeFile('config/$fileName', config);
    
    return fileName;
  }
}
```

### 4.4 生成完整App

```dart
class AppGenerator {
  Future<String> generateApp(String need) async {
    // 需要更复杂的代码生成
    String appCode = await llmGenerate(AppPrompt);
    
    String fileName = 'app_$need.dart';
    await writeFile('apps/$fileName', appCode);
    
    // 初始化
    await Process.run('flutter', ['pub', 'get']);
    
    return fileName;
  }
}
```

String getFullPrompt(String userInput) '''
你是产物生成专家。
