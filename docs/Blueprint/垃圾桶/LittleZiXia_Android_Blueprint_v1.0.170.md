## 三、核心新增功能

### 3.1 本地模型层（对齐苹果）

**目标**: Android 手机本地运行量化大模型

**技术方案**:
```
400B模型 → GGUF量化 → 手机能跑的尺寸（1.5B~70B）
         ↓
   llama.cpp Android NDK → 本地推理
         ↓
   多设备分布式 → 算力互助
```

**实现路径**:
1. 编译 llama.cpp Android NDK 版本
2. 支持 GGUF 模型加载（参考苹果 `NativeLlamaBackend.md`）
3. 对接 PocketLLMRuntime 抽象接口
4. 实现流式输出 + 性能指标

**参考**:
- 苹果项目: `LittleZiXiaPocketLLMLlama`
- 官方仓库: `ggerganov/llama.cpp`
- 量化: 1.5-bit ~ 8-bit 量化

### 3.2 分布式算力（核心创新）

**目标**: 多设备算力互助，类Hadoop分布式计算

**架构**:
```
           Master（任务分解）
               ↓
        ┌──────┴──────┐
   Device A    Device B    Device C
   (1.5B)      (7B)       (70B)
               ↓
        ┌──────┴──────┐
           汇总结果
```

**任务流程**:
1. 用户输入复杂任务
2. Master 任务分解器拆分
3. 根据设备算力分配子任务
4. 各设备并行执行
5. 结果汇总返回

**关键点**:
- 任务分解算法
- 设备能力感知（能跑多大模型）
- 结果合并策略
- 断线重连
