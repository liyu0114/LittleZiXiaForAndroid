## 一、前言

分布式计算 refers to Hadoop-style task decomposition.
This is about splitting user tasks into logical subtasks and executing on different devices.

## 二、目标

- 用户任务 → 拆分成"纯逻辑子任务"
- 不同设备执行不同子任务
- 结果汇总返回

## 三、技术方案

### 3.1 任务分片

```
输入："分析北京和上海天气"
→ 拆分成：
  - 子任务1：查询北京天气
  - 子任务2：查询上海天气
```

### 3.2 设备分配

- 设备A执行子任务1
- 设备B执行子任务2
- 结果汇总
