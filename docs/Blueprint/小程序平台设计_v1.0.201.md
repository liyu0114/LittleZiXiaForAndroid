## 三、任务解决时自制工具

### 3.1 自制工具选项

当LLM分析任务时：

```
1. 需要什么工具？
2. 没有现成工具？
3. 选项：
   - 创建Skill（代码）
   - 创建小程序（带UI）
   - 写代码脚本
   - 创建App（完整应用）
```

### 3.2 选择标准

| 工具类型 | 适用场景 |
|---------|----------|
| **Skill** | 纯逻辑、无UI |
| **小程序** | 需要UI界面、沙盒运行 |
| **脚本** | 简单任务（shell/python/js） |
| **App** | 完整Flutter应用 |

## 四、小程序作为AgentTool

### 4.1 封装为工具

```dart
class MiniProgramTool extends AgentTool {
  final MiniProgram program;
  final SandboxRuntime sandbox;
  
  @override
  String get name => 'miniapp_${program.id}';
  
  @override
  String get description => program.description;
  
  @override
  Future<AgentToolResult> execute(Map arguments) async {
    var result = await sandbox.run(program, arguments);
    return AgentToolResult.success(result);
  }
}
```

### 4.2 注册到工具系统

```dart
class ToolRegistry {
  List<AgentTool> tools = [];
  
  void registerMiniProgram(MiniProgram program) {
    var tool = MiniProgramTool(program);
    tools.add(tool);
  }
}
```

## 六、工作流程

### 6.1 用户需要某功能

```
用户：帮我做一个汇率计算器
    ↓
分析：需要UI工具
    ↓
自制：创建小程序
    ↓
执行：运行小程序
    ↓
结果：返回计算器界面
```

### 6.2 LLM自动选择

```
LLM判断：
- 简单任务 → Skill
- 需要UI → 小程序
- 复杂任务 → 写代码
```
