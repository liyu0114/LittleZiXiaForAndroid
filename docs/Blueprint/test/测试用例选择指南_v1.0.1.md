## 一、测试用例选择方法

### 1.1 怎么选测试用例？

**原则：覆盖核心路径**

| 方法 | 说明 |
|------|------|
| 等价类划分 | 典型/边界/异常各选1个 |
| 边界值 | 空/1/正常/超大 |
| 错误处理 | 正常/网络错/参数错 |

### 1.2 各服务测试用例

#### 任务分解

```
✅ 典型：用"帮我算24点" → 应分解为[生成牌组,计算24点,返回结果]
✅ 边界：用"" → 应提示输入
✅ 错误：用无法分解的任务 → 应直接执行
```

#### 断线重连

```
✅ 典型：发送中断线 → 应缓存 → 恢复后重发
✅ 边界：多条消息断线 → 应按顺序重发
✅ 错误：服务器不可达 → 应提示
```

#### 游戏托管

```
✅ 典型：30秒无操作 → 应AI托管
✅ 边界：提前操作 → 应取消托管
✅ 错误：游戏进行中强退 → 应记录状态
```

## 二、联网怎么测试

### 2.1 模拟断网

```dart
// 在测试中模拟
void testNetworkRecovery() {
  // 1. 模拟正常网络
  when(network.isConnected).thenReturn(true);
  
  // 2. 发送消息
  service.sendMessage("test");
  
  // 3. 模拟断网
  when(network.isConnected).thenReturn(false);
  
  // 4. 验证消息缓存
  expect(queue.hasMessage("test"), true);
  
  // 5. 模拟恢复
  when(network.isConnected).thenReturn(true);
  
  // 6. 验证重发
  service.recover();
  verify(network.send("test"), times(1));
}
```

### 2.2 真机断网测试

| 你操作 | 预期 |
|--------|------|
| 正常发消息 | 对方收到 |
| 关闭WIFI | 显示断线 |
| 关闭流量 | 显示断线 |
| 打开网络 | 自动重连+重发 |

## 三、大任务分解怎么测试

### 3.1 任务分解逻辑

```
输入：帮我查天气+发邮件+整理文件
预期：
  1. [查天气 → 发邮件 → 整理文件]
  2. 天气和邮件可并行
  3. 整理依赖邮件结果
```

### 3.2 测试用例

```dart
void testTaskDecomposition() {
  // ✅ 简单任务
  var result = decomposer.decompose("查天气");
  expect(result.subTasks.length, 1);
  
  // ✅ 并行任务
  result = decomposer.decompose("同时查天气和邮件");
  expect(result.canParallel, true);
  
  // ✅ 串行任务
  result = decomposer.decompose("查天气然后发邮件");
  expect(result.subTasks[1].dependsOn(result.subTasks[0]), true);
  
  // ✅ 复杂任务
  result = decomposer.decompose("帮我做XXX");
  expect(result.subTasks.length, greaterThan(0));
}
```

### 3.3 真机测试

| 输入 | 预期分解 |
|------|----------|
| 帮我算24点 | 1个子任务：计算 |
| 帮我查天气并告诉我 | 2个子任务：查+发 |
| 帮我整理文件+发邮件+查天气 | 3个（可并行的先执行） |

## 四、算力贡献怎么测试

### 4.1 算力贡献流程

```
贡献者A：注册 → 激活 → 开始贡献
任务池：提交任务 → 分发给A → 收集结果 → 积分
```

### 4.2 测试用例

```dart
void testComputePower() {
  // ✅ 注册贡献者
  manager.register("设备A", ComputeType.gpu);
  expect(manager.contributors.length, 1);
  
  // ✅ 激活贡献
  manager.activate("设备A");
  expect(manager.isActive("设备A"), true);
  
  // ✅ 提交任务
  var taskId = manager.submitTask("计算", {"data": "xxx"});
  expect(taskId, isNotNull);
  
  // ✅ 更新进度
  manager.updateProgress(taskId, 50);
  expect(manager.getProgress(taskId), 50);
  
  // ✅ 完成任务
  manager.updateProgress(taskId, 100);
  manager.addScore("设备A", 10);
  expect(manager.getScore("设备A"), 10);
}
```

### 4.3 真机测试

| 步骤 | 你操作 | 我验证 |
|------|-------|-------|
| 1 | 打开贡献算力 | 看到设备在线 |
| 2 | 提交计算任务 | 任务分发 |
| 3 | 计算完成 | 收到结果+积分 |
| 4 | 查看积分 | 排行榜更新 |

## 五、复杂度分层测试

### 5.1 L1 基本功能（必须过）

```
任务分解能工作
网络能断能连

```
分解+执行+返回
断网+缓存+重发+确认

```
多任务并行+串行混合
多设备分布式
多轮对话+上下文
```
