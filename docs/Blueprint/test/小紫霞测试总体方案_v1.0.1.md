### 2.2 连接方式详解

#### USB连接（单设备）

```
步骤1：手机设置开发者模式
  设置 → 关于手机 → 版本号 → 点7次
  
步骤2：开启USB调试
  设置 → 系统 → 开发人员选项 → USB调试（开）

步骤3：连接电脑
  USB线连接 → 手机点"允许"

步骤4：验证
  adb devices → 看到设备号
```

#### WiFi连接（多设备）

```
步骤1：同一WiFi网络
  手机和电脑连同一路由器

步骤2：获取手机IP
  设置 → 关于手机 → IP地址

步骤3：连接
  adb connect 192.168.1.XXX:5555
```
