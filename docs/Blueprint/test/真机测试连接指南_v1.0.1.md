# 真机测试连接详细指南

> **版本**: v1.0.1
> **更新**: 2026-05-05

---

## 一、测试架构

```
电脑（我）← USB → 手机（你）
    │
    ├── 安装APK
    ├── 查看日志
    └── 截图（需要授权）
```

---

## 二、手机端设置

### 2.1 开启开发者模式

```
步骤1：设置
步骤2：关于手机
步骤3：版本号（emui版本）
步骤4：点击7次 → 提示"已开启开发者选项"
```

### 2.2 开启USB调试

```
步骤1：设置
步骤2：系统 → 开发人员选项
步骤3：USB调试 → 开启
步骤4：授权提示 → 允许
```

### 2.3 USB连接电脑

```
硬件：USB线（市售手机线，不要只充电线）
连接：手机 → 电脑USB口
手机提示：选择"传输文件"或"仅充电"
电脑提示：允许USB调试？→ 允许
```

---

## 三、电脑端验证

### 3.1 检查ADB

```bash
# 查看已连接设备
adb devices

# 预期输出：
# List of devices attached
# XXX device
```

### 3.2 安装APK

```bash
# 构建并安装
flutter install

# 或手动安装
adb install app-release.apk
```

---

## 四、测试流程

### 4.1 你测试、我配合

```
1. 你：连接手机 USB
2. 我：检查连接
3. 你：安装APK
4. 你：操作手机测试功能
5. 你：告诉我结果
6. 我：记录问题
```

### 4.2 日志查看

```bash
# 实时日志
adb logcat | grep LittleZiXia

# 或 flutter
flutter logs
```

## 五、所需设备

| 设备 | 状态 | 说明 |
|------|------|------|
| 华为手机 | 你的 | 需要设置开发者模式 |
| USB线 | 你的 | 需要数据线，不是充电线 |
| 电脑 | 我的 | 已有Flutter环境 |

---

## 六、你需要做的具体步骤

### 步骤1：手机设置（2分钟）

```
设置 → 关于手机 → 版本号（点7次）
设置 → 系统 → 开发人员选项 → USB调试（开）
```

### 步骤2：连接手机（30秒）

```
1. USB线连接手机和电脑
2. 手机选择"传输文件"
3. 电脑弹出"允许调试"→ 点"允许"
```

### 步骤3：验证（30秒）

```bash
# 在我这边运行
adb devices

# 看到设备号即成功
```

## 七、问题解决

| 问题 | 解决方法 |
|------|----------|
| 找不到adb | 环境变量未设置，重启终端 |
| 手机无反应 | 换USB口或换线 |
| 调试未授权 | 点手机上的"允许" |
| 驱动问题 | 安装华为手机助手 |
