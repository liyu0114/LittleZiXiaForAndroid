## 三、集成步骤

### 步骤1：复制目录

```bash
# 复制30个新目录到openclaw_app
cp -r D:\LittleZiXia\lib\services\analytics D:\LittleZiXia\openclaw_app\lib\services\
cp -r D:\LittleZiXia\lib\services\backup D:\LittleZiXia\openclaw_app\lib\services\
...
```

### 步骤2：解决依赖

检查新服务中使用的包是否都在pubspec.yaml中。

### 步骤3：构建测试

```bash
flutter build apk --debug
```

### 步骤4：运行测试

```bash
flutter test
```
