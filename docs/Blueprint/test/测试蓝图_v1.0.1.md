## 二、测试分层

### L1 单元测试（底部）

```
目标：每个服务独立正确
谁：我自动跑
环境：本地Flutter
覆盖率：核心服务100%
```

| 测试什么 | 怎么测 |
|----------|--------|
| 单个服务 | `flutter test test/xxx_test.dart` |
| 边界条件 | 空/1个/1000个 |
| 异常处理 | 抛异常/返回错误 |

---

### L2 冒烟测试

```
目标：基本功能可用
谁：我自动跑
环境：模拟器/真机
标准：关键路径跑通
```

| 测试什么 | 怎么测 |
|----------|--------|
| App能启动 | 构建APK，安装，运行 |
| 能收消息 | 发消息，收回复 |
| 能断线 | 模拟断网，验证提示 |

---

### L3 集成测试

```
目标：多模块配合正确
谁：我+你配合
环境：真机
标准：核心流程跑通
```

| 测试什么 | 怎么测 |
|----------|--------|
| 任务解决流程 | 发任务→分解→执行→返回 |
| 断线重连流程 | 断→缓存→恢复→重发 |
| 游戏托管流程 | 超时→托管→恢复 |

---

### L4 验收测试（顶部）


## 五、测试策略

### 5.1 先难后易

```
先跑集成测试（L3）
再跑单元测试（L1）
最后跑验收（L4）
```

### 5.2 先核心后外围

```
① 任务分解（核心）
② 网络重连（核心）
③ 游戏托管（重要）
④ 其他功能（一般）
```

### 5.3 先自动化后手动

```
① 我跑自动化测试
② 你跑手动测试
③ 发现问题我修复
④ 再跑一轮
```
