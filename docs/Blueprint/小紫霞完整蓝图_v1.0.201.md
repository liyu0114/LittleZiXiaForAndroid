## 一、整体架构

```
用户请求（任务）
    ↓
┌─────────────────────────────────────────────────────────────┐
│  第1层：任务分析 + 分解                                   │
│  • LLM分析需求                                            │
│  • 判断是否需要分解                                        │
│  • 拆分成子任务（串行/并行）                               │
└─────────────────────────────────────────────────────────────┘
    ↓
┌─────────────────────────────────────────────────────────────┐
│  第2层：工具准备                                          │
│  • 检查现有工具                                           │
│  • 搜索SkillHub                                           │
│  • 技能自造（Skill/Script/App）                            │
│  • 自制小程序                                         │
│  • 命令行脚本                                         │
└─────────────────────────────────────────────────────────────┘
    ↓
┌─────────────────────────────────────────────────────────────┐
│  第3层：执行分发                                          │
│  • 单设备执行                                             │
│  • 分布式计算（多设备）                                    │
│  • 贡献算力（计算单元）                                   │
└─────────────────────────────────────────────────────────────┘
    ↓
┌─────────────────────────────────────────────────────────────┐
│  第4层：结果汇总                                          │
│  • 收集结果                                              │
│  • 合并汇总                                              │
│  • 返回用户                                              │
└─────────────────────────────────────────────────────────────┘
```
