## 三、技术架构

### 3.1 目标文件结构

```
lib/
├── core/                    # 核心
│   └── app_state.dart       
├── features/               # 功能模块
│   ├── agent/              # Agent任务执行
│   ├── skills/             # Skill系统
│   ├── chat/               # 聊天
│   ├── games/              # 游戏
│   ├── llm/                # LLM相关
│   ├── task_decompose/     # 任务分解
│   └── collab/             # 协作
├── devices/               # 设备能力
│   ├── voice/              # 语音
│   ├── vision/             # 视觉
│   ├── sensors/           # 传感器
│   └── native/             # 本地模型
├── services/              # 公共服务
│   ├── memory/             # 记忆
│   ├── web/               # Web
│   └── remote/             # 远程
├── sandbox/              # 沙盒环境
└── ui/
    └── screens/
```

### 3.2 联网层级

```
优先级1: P2P直连（就近）
    ↓
优先级2: Tailscale
    ↓
优先级3: 中央网关（有条件）
```
