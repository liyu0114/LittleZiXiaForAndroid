## 一、整体架构

```
用户请求（任务）
    ↓
┌─────────────────────────────────────────────────────────────┐
│  第1层：任务分析 + 分解                                   │
│  • LLM分析需求                                            │
│  • 判断是否需要分解                                        │
│  • 拆分成子任务（串行/并行）                               │
└─────────────────────────────────────────────────────────────┘
    ↓
┌─────────────────────────────────────────────────────────────┐
│  第2层：工具准备                                          │
│  • 检查现有工具                                           │
│  • 搜索SkillHub                                           │
│  • 技能自造（Skill/Script/App）                            │
│  • 自制小程序                                         │
│  • 命令行脚本                                         │
└─────────────────────────────────────────────────────────────┘
    ↓
┌─────────────────────────────────────────────────────────────┐
│  第3层：执行分发                                          │
│  • 单设备执行                                             │
│  • 分布式计算（多设备）                                    │
│  • 贡献算力（计算单元）                                   │
└─────────────────────────────────────────────────────────────┘
    ↓
┌─────────────────────────────────────────────────────────────┐
│  第4层：结果汇总                                          │
│  • 收集结果                                              │
│  • 合并汇总                                              │
│  • 返回用户                                              │
└─────────────────────────────────────────────────────────────┘
```

## 四、机器人协作

### 4.1 架构

```
人类层（最高决策）
    ↓
机器人层（自主讨论）
    ↓
任务执行层
```

### 4.2 人类权限

| 角色 | 指派任务 | 启动讨论 | 终止讨论 | 覆盖 |
|------|----------|----------|----------|------|
| 群主 | ✓ | ✓ | ✓ | ✓ |
| 管理员 | ✓ | ✓ | ✓ | ✓ |
| 成员 | ✓ | ✓ | ✓ | ✗ |

### 4.3 机器人权限

| 角色 | 发言 | 做决定 | 委派 |
|------|------|--------|------|
| leader | ✓ | ✓ | ✓ |
| member | ✓ | ✗ | ✓ |
| observer | ✗ | ✗ | ✗ |

## 五、网络架构

### 5.1 混合网络

```
应用层（透明）
    ↓
NWA网络抽象层
    ↓
局域网 / Tailscale / 中继
```

### 5.2 断线处理

| 场景 | 处理 |
|------|------|
| 消息断线 | 队列缓存+重发 |
| 任务断线 | 任务重分发 |
| 游戏断线 | 30秒超时+AI托管 |
| 分布式断线 | 重新分发 |
| 贡献算力断线 | Checkpoint恢复 |

## 六、超长上下文

### 6.1 项目结构

```
项目 → 对话 → 消息 → 文件
```

### 6.2 压缩机制

- 超过20条 → 生成摘要
- 保留摘要+最近10条
- 存储SQLite（永久）
