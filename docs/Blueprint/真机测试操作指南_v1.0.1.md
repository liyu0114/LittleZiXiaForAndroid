## 一、你在电脑旁时做

### 步骤1：手机设置（一次性，2分钟）

```
位置：手机设置

① 设置 → 关于手机
② 找到「版本号」（或emui版本）
③ 连续点击7次
④ 提示「已开启开发者选项」

⑤ 设置 → 系统 → 开发人员选项
⑥ 找到「USB调试」
⑦ 开启 → 允许
```

### 步骤2：连接手机

```
硬件：USB线（数据线，不是只充电的线）
连接：手机USB口 → 电脑USB口

手机弹出：是否允许USB调试？
点击：「允许」（可勾选始终允许）
```

### 步骤3：验证连接

我来运行：
```bash
adb devices
```

看到手机设备号即成功。

### 步骤4：安装APK

我来运行：
```bash
flutter install
```

或你手动安装APK文件。

### 步骤5：开始测试

你操作手机，我记录结果。

## 四、遇到问题

| 表现 | 原因 | 解决 |
|------|------|------|
| 手机无反应 | 没开开发者模式 | 去设置打开 |
| 连接不上 | USB线问题 | 换线或换口 |
| 没弹授权 | 没连对 | 重新插拔 |
| 安装失败 | 没签名 | 我重新构建 |
