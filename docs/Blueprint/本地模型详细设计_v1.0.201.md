## 一、目标

---

## 二、技术路径：两者结合

### 2.1 本地模型（量化）

| 步骤 | 技术 | 说明 |
|------|------|------|
| 1 | llama.cpp | 纯C++实现 |
| 2 | 量化 | 400B→手机能跑的尺寸 |
| 3 | GGUF格式 | 统一模型格式 |

**手机能跑多大**：1GB-14GB（根据内存）

### 2.2 分布式（两层）

| 层次 | 类比 | 说明 |
|------|------|------|
| **分布式计算** | Hadoop | 任务级别分解执行 |
| **贡献算力** | CUDA | 底层计算单元并行 |

```
用户请求
       ↓
┌─────────────────────────────────────┐
│   第一层：分布式计算（类似Hadoop）  │
│   任务拆解 → 子任务分配 → 各设备执行 │
└─────────────────────────────────────┘
       ↓
┌─────────────────────────────────────┐
│   第二层：贡献算力（类似CUDA）      │
│   计算单元 → 多设备并行 → 汇总     │
└─────────────────────────────────────┘
       ↓
结果返回
```
