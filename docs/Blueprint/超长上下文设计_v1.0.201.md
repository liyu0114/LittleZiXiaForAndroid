## 二、永久存储配合

### 2.1 存储架构

```
┌─────────────────────────────────────────┐
│              存储层                     │
│  ┌──────────┐  ┌──────────┐       │
│  │ SQLite  │  │ 文件系统 │       │
│  │ (本地)  │  │ (文件)  │       │
│  └──────────┘  └──────────┘       │
│         ↓                    │
│  ┌─────────────────┐            │
│  │ 可选：云端备份 │            │
│  └─────────────────┘            │
└─────────────────────────────────────────┘
```

### 2.2 存储位置

```
优先：D盘
    ↓
项目：/storage/projects/
    ↓
对话：/storage/projects/{id}/conversations/
    ↓
文件：/storage/projects/{id}/files/
```

### 2.3 数据库表

```sql
-- 项目表
CREATE TABLE projects (
  id TEXT PRIMARY KEY,
  name TEXT,
  description TEXT,
  created INTEGER,
  updated INTEGER
);

-- 对话表
CREATE TABLE conversations (
  id TEXT PRIMARY KEY,
  project_id TEXT,
  summary TEXT,
  created INTEGER,
  FOREIGN KEY (project_id) REFERENCES projects(id)
);

-- 消息表
CREATE TABLE messages (
  id TEXT PRIMARY KEY,
  conversation_id TEXT,
  sender TEXT,
  content TEXT,
  timestamp INTEGER,
  FOREIGN KEY (conversation_id) REFERENCES conversations(id)
);

-- 文件表
CREATE TABLE files (
  id TEXT PRIMARY KEY,
  project_id TEXT,
  name TEXT,
  path TEXT,
  size INTEGER,
  FOREIGN KEY (project_id) REFERENCES projects(id)
);
```

## 三、上下文压缩机制

### 3.1 压缩触发条件

| 条件 | 动作 |
|------|------|
| 对话超过20条 | 自动压缩 |
| 项目总大小超限 | 归档旧对话 |
| 用户问历史 | RAG检索 |

### 3.2 压缩流程

```
对话进行中...
    ↓
达到阈值（20条消息）
    ↓
生成摘要："用户想要X，机器人做了Y..."
    ↓
保留：摘要 + 最近10条
    ↓
删除：旧的中间消息
    ↓
保存到SQLite（永久存储）
```

## 四、历史检索（RAG）

### 4.1 用户问历史

```
用户：上次那个项目怎么做？
    ↓
检索所有项目摘要（从SQLite）
    ↓
找到相关项目
    ↓
返回历史记录
```

### 4.2 检索流程

```dart
Future<List<HistoryResult>> search(String query) async {
  // 1. 从SQLite获取所有摘要
  var summaries = await db.query('conversations', 
    columns: ['id', 'project_id', 'summary']
  );
  
  // 2. 向量相似度搜索
  var results = await vectorSearch(query, summaries);
  
  // 3. 返回相关历史
  return results;
}
```

## 五、完整流程

```
1. 用户创建项目
   ↓ 保存到SQLite
2. 对话进行
   ↓ 消息存储SQLite
3. 超过阈值
   ↓ 生成摘要 + 压缩
4. 保存摘要到SQLite
5. 用户问历史
   ↓ RAG检索
6. 找到相关项目
7. 返回历史
```
