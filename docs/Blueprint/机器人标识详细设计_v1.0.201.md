### 问题1：多台设备都叫"小紫霞"，不知道艾特哪个

```
场景：
- 群聊里有3台设备
- 每台设备的机器人都叫"小紫霞"
- @小紫霞 不知道响应的是哪一台
```

```
场景：
- 群聊里有多个人类 + 多个机器人
```

## 二、解决方案

### 2.1 设备唯一标识

```dart
class DeviceIdentity {
  String deviceId;    // 设备唯一ID
  String deviceName;  // 设备名（如"小紫霞-手机A"）
  String shortId;     // 短ID（3位）
}
```

**显示**：
```
@小紫霞(设备1) → @小紫霞_abc
@小紫霞(设备2) → @小紫霞_def  
@小紫霞(设备3) → @小紫霞_ghi
```

### 2.2 消息路由（按设备）

```dart
class MessageRouter {
  // 消息带设备ID
  Future<String> route(Message msg) async {
    if (msg.hasAtDevice()) {
      // 艾特特定设备 → 发给那个设备
      return sendToDevice(msg.atDeviceId, msg);
    } else if (msg.hasAtRobot()) {
      // 艾特机器人 → 发给任一设备（负载均衡）
      return sendToBestDevice(msg.robotId, msg);
    } else {
      // 没有艾特 → 发给默认设备
      return sendToDefault(msg);
    }
  }
}
```

## 五、实现细节

### 5.1 设备发现时注册

```dart
onDeviceFound(Device device) {
  // 注册到群聊
  group.addDevice(device);
  
  // 广播给所有设备
  broadcast(DeviceOnline(device));
}
```

### 5.2 消息路由实现

```dart
Future<String> route(Message msg) async {
  var target = msg.target;
  
  if (target.isDeviceSpecific) {
    // 指定设备
    return sendToDevice(target.deviceId, msg);
  } else if (target.isRobotOnly) {
    // 指定机器人（任意设备）
    return sendToBestDevice(target.robotId, msg);
  } else {
    // 默认
    return sendToDefault(msg);
  }
}
```
