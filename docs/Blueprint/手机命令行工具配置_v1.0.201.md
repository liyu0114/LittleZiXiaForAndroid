## 一、权限配置

### 1.1 ADB调试权限

```
步骤：
1. 手机设置 → 关于手机
2. 连续点击"版本号"7次 → 开启开发者模式
3. 设置 → 开发者选项 → 开启USB调试
4. 数据线连接电脑
5. 电脑执行: adb devices
6. 手机确认授权
```

### 1.2 Root权限（可选但推荐）

```
方案A：Magisk Root
需要的条件：
1. Bootloader可解锁（检查厂商政策）
2. 电脑刷入Magisk
3. Magisk APP中授予ADB root权限

操作：
1. 解锁Bootloader（厂商允许）
2. 刷入Magisk的boot.img
3. 重启后安装Magisk APP
4. 在Magisk中允许ADB root请求
```

### 1.3 无Root方案

```
如果不能Root，使用Termux替代：
- F-Droid安装Termux
- 在Termux中安装工具
- 通过ADB端口转发使用
```

## 二、手机环境配置

### 2.1 安装Termux（推荐）

```
从F-Droid下载Termux：
https://f-droid.org/packages/com.termux/

安装后运行：
pkg update
pkg upgrade
```

### 2.2 安装必要工具

```bash
# 基础工具
pkg install python nodejs git curl wget

# Python常用库

# Node常用
npm install -g some-tool
```

```bash

# 测试Node
node --version

# 测试OpenClaw
npx openclaw --help
```

## 三、ADB端口转发（无Root方案）

```bash
# 让电脑可以访问手机上的服务
adb forward tcp:8022 tcp:8022  # Termux的SSH端口

# 或者用adb shell直接执行命令
adb shell "ls /data/data/com.termux/files/home"
```

## 四、Flutterm App集成

### 4.1 命令执行工具

```dart
import 'dart:io';

class CommandExecutor {
  // 使用ADB执行命令
  Future<String> executeViaADB(String command) async {
    final result = await Process.run('adb', ['shell', command]);
    return result.stdout;
  }
  
  // 如果有Termux SSH
  Future<String> executeViaSSH(String command) async {
    final result = await Process.run('ssh', ['-p', '8022', 'localhost', command]);
    return result.stdout;
  }
}
```

## 五、完整工作流

```
用户请求
   ↓
Agent分析任务
   ↓
需要命令行工具？
   ↓
CommandExecutor.execute("命令")
   ↓
┌─────────────────────────────────────┐
│  检查权限配置                        │
│  - ADB连接 ✓                         │
│  - Root可用？ → 执行                 │
│  - Termux可用？ → SSH执行            │
└─────────────────────────────────────┘
   ↓
返回结果给用户
```
