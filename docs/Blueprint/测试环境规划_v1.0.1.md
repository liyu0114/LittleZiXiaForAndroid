## 二、当前阶段（第1期）

### 2.1 设备清单

| 设备 | 连接方式 | 用途 | 状态 |
|------|---------|------|------|
| 华为手机1 | USB | 主测试机 | 🔲 等你设置 |
| 华为手机2 | WiFi | 并行测试 | 🔲 需购买 |
| 华为手机3 | WiFi | 并行测试 | 🔲 需购买 |
| 华为手机4 | WiFi | 备用 | 🔲 需购买 |

### 2.2 连接方式

#### USB连接（手机1）

```
手机1 → USB线 → 电脑USB口
优势：稳定、可直接安装APK、可看日志
劣势：只能1台
```

#### WiFi连接（手机2-4）

```
手机2-4 → WiFi → 路由器 → 电脑
优势：可多台并行
劣势：需要网络环境
```

### 2.3 USB连接步骤

```
第1步：手机设置
  设置 → 关于手机 → 版本号（点7次）
  设置 → 系统 → 开发人员选项 → USB调试（开）

第2步：连接电脑
  USB线连接手机和电脑
  手机点"允许"

第3步：验证
  adb devices
  # 看到设备号即成功

第4步：安装
  flutter install
```
