## 一、系统总纲

### 1.1 核心愿景
- **目标**: 将手机从"遥控器"升级为"主机"
- **对标**: OpenClaw 的核心设计思想
- **特点**: 本地执行 + 移动端特种能力 + Skill生态

### 1.2 架构分层

```
┌─────────────────────────────────────────────────────────┐
│                    用户交互层                        │
│  (聊天界面、群聊、游戏、SkillHub、设置)               │
├─────────────────────────────────────────────────────────┤
│                    业务能力层                      │
│  (Agent Loop、任务执行、技能系统、群聊协作)          │
├─────────────────────────────────────────────────────────┤
│                    基础服务层                      │
│  (LLM服务、网络服务、存储服务、上下文管理)          │
├─────────────────────────────────────────────────────────┤
│                    设备能力层（手脚）             │
│  (摄像头、麦克风、GPS、传感器、通知等)           │
└─────────────────────────────────────────────────────────┘
```

## 三、详细设计

### 3.1 任务执行流程（参考 OpenClaw）

```
用户输入
    ↓
意图识别（_routeIntent）
    ↓
任务规划（先列出完整计划）
    ↓
任务分解（AgentLoop → 多个子任务）
    ↓
执行调度
    ├─ Skill 执行器
    ├─ Agent 工具调用
    ├─ 原生能力调用
    └─ LLM 直接回复
    ↓
结果汇总 + 记忆沉淀
```

### 3.2 Skill 机制设计

```
┌─────────────────────────────────────────────┐
│ Skill 加载层                               │
│  ├─ 预装 Skill (assets/skills/)            │
│  ├─ SkillHub 安装                         │
│  └─ 运行时学习                           │
├─────────────────────────────────────────────┤
│ Skill 执行层                              │
│  ├─ MarkdownSkillExecutor              │
│  ├─ 原生能力桥接                         │
│  └─ 工具注册                             │
├─────────────────────────────────────────────┤
│ Skill 生命周期                            │
│  ├─ 安装 / 卸载                         │
│  ├─ 启用 / 禁用                         │
│  └─ 更新 / 回滚                         │
└─────────────────────────────────────────────┘
```

### 3.3 群聊协作设计

```
群聊消息
    ↓
角色识别（@谁）
    ↓
技能匹配
    ↓
执行协作
    ├─ 串行执行
    ├─ 并行执行
    └─ 回调执行
    ↓
结果返回
```

## 六、开发规范

### 6.1 文件命名规范
```
lib/
├── screens/        # 页面（xxx_screen.dart）
├── services/       # 服务（xxx_service.dart）
├── providers/     # 状态管理（xxx_provider.dart）
├── widgets/      # 组件（xxx_widget.dart）
├── models/        # 数据模型（xxx_model.dart）
└── config/        # 配置（xxx_config.dart）
```

### 6.2 版本管理
- 版本号：`pubspec.yaml` + `lib/config/app_version.dart` + `settings_screen.dart` 三处同步
- 提交记录：每次修改必须更新 `REQUIREMENTS.md`
- 工作日志：`QA/worklog/YYYY-MM-DD.md`

### 6.3 代码检查
每次提交前：
- [ ] 运行 `flutter analyze`
- [ ] 检查无新增警告
- [ ] 测试核心流程
