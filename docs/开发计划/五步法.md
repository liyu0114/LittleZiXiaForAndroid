# LittleZiXia 开发五步法

> **版本**: v1.0.0_20250504
> **规范**: 苹果团队工作方式

---

## 五步流程

### 第一步：需求分析
- 读取 `D:\LittleZiXia\REQUIREMENTS.md` 了解历史版本
- 读取对应平台的 Master Plan
- 分析用户需求，拆解为技术任务

### 第二步：方案设计
- 在 `开发计划/` 目录下创建任务文档
- 包含：背景、目标、技术方案、里程碑
- 需要确认的选择题列在待确认问题中

### 第三步：开发实现
- 修改对应代码文件
- 同步更新 `D:\LittleZiXia\REQUIREMENTS.md`
- 写入 `D:\LittleZiXia\QA\worklog\YYYY-MM-DD.md`

### 第四步：测试验证
- 构建 debug/release APK
- 测试并记录问题
- 修复直到验收

### 第五步：提交发布
- 提交到 GitHub（如果网络不通则本地提交）
- 更新版本号 + 更新 REQUIREMENTS.md
- 记录到 daily worklog

---

## 代码瘦身工作（持续进行）

每次开发时同步进行：
1. 检查是否有冗余代码/文件
2. 检查重复功能是否可以合并
3. 检查废弃的 Skill/HardCode
4. 记录到 `D:\LittleZiXia\QA\code-cleanup.md`

```
│   ├── 开发计划_vX.X.X_DATE.md

│   ├── code-cleanup.md  # 代码瘦身记录
│   └── TASK_STATUS.md   # 任务状态

    └── ARCHITECTURE.md
```

## 关键词触发

当你说 **"按五步法自主开发"** 时，我将：
1. 读取最新 REQUIREMENTS.md 了解当前版本
2. 读取 Master Plan 了解架构
3. 分析需求并设计方案
4. 执行开发并记录
5. 完成后推送 GitHub
